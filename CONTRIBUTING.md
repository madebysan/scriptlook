# Contributing to Scriptlook

Thanks for helping improve Scriptlook.

Before opening a pull request:

1. Keep the change focused and explain the user-facing reason for it.
2. Do not add copyrighted screenplay text, commercial-film demo media, API keys, or generated asset batches.
3. Run `npm test`, `npm run typecheck`, `npm run lint`, and `npm run build`.
4. Include screenshots for visible interface changes.

Please open an issue before starting a large feature or architectural change. This keeps maintenance expectations clear and avoids duplicate work.
